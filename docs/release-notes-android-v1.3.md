# Android 1.3 发布说明

### 新功能：AI 控制键盘

在九宫格中点按 **ChatGPT、Codex 或 Cursor**，手机不再只是启动 Mac 应用，而是进入该应用专属的 **控制键盘**（左上角返回九宫格）。

- **Codex**：批准 / 拒绝、新会话、推理旋钮、Skills 等
- **ChatGPT**：新对话、PTT、发送、命令菜单、侧边栏等
- **Cursor**：PTT、发送、Chat、命令面板、接受 / 拒绝、终端等
- 键位按目标应用独立保存；可在设置中重映射

### 按住说话（PTT）

- 按住 **PTT** 用手机麦克风说话；松手后识别文字填入 Mac 上对应应用的输入框
- 识别在 Android 本机完成，**音频不离开手机**，仅最终文字经 Wi‑Fi 发送
- 双击 PTT 可免提录音；首次使用需允许 **麦克风** 权限

### Tab 左右滑动

- 已配对后，九宫格页与设置页支持 **左右滑动** 切换（也可点按底栏）

### 显示桌面

- Apps 九宫格上 **双指下滑**，隐藏 Mac 上全部已打开应用并显示桌面

### 其它

- 升级 **Google Play Billing Library** 至 **9.1.0**，满足 Play 结算库版本要求

### 要求

- Mac 端需更新至 **1.2.7** 或更高，并与手机同一局域网配对
- 使用 AI 控制键盘时，请在 Mac「系统设置 → 隐私与安全性」中允许 **辅助功能** 与 **自动化**

### 安装包

- 附件：`TreeletHub-Android-1.3.apk`（`versionCode` 5）
- 也可从 [Google Play](https://play.google.com/store/apps/details?id=com.treelet.treelethub) 安装

### 侧载安装（APK）

1. 下载 APK。
2. 在系统设置中允许「安装未知应用」（按机型路径略有差异）。
3. 打开 APK 完成安装。
4. 与 Mac 同一 Wi‑Fi，打开 TreeletHub 输入配对码连接。
