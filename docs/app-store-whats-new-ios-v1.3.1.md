## 此版本的新增内容（What's New）

### 简体中文

• 手机蜂巢启动墙：App Store 图标 + 公开 URL 一键打开
• 桌面小组件先进入 TreeletHub，再打开目标应用
• 通讯录选人后一键呼叫
• 相机走系统拍照界面（无公开 URL 时）
• 可搜 App Store；仅可打开的应用可加入蜂巢
• 修正高德 / 京东 / 滴滴 / 喜马拉雅等图标查找

### English

• Honeycomb phone launcher with App Store artwork and one-tap open for apps with a public URL
• Home Screen widget opens TreeletHub, then the target app
• One-tap calling from selected contacts
• System camera capture when Camera has no public URL
• App Store search; only launchable apps can be added
• Fixes for map / shopping / music icon lookups
