## TreeletHub 1.3.1 for Android

与当前 iPhone 体验对齐：蜂巢启动墙、去掉本机 AI 控制键盘，国内下载走 Cloudflare CDN。

### 蜂巢启动墙

- Apps 页改为 **Watch 风格蜂巢启动墙**（与 iPhone / Mac 一致）：捏合缩放、拖动浏览、长按进入编辑后拖拽换位。
- 多页非空槽位展平为一面墙；底栏仅 **应用** 与 **设置**。
- 空白处双击可复位默认缩放。

### 与 iOS 对齐

- 点按仅启动 Mac 应用 / 快捷方式；音量、亮度、媒体走内联控件。
- 已移除 Codex 控制键盘、本机听写与麦克风权限。
- 已移除本机 Play 订阅门控；Pro 能力以 Mac 端为准。
- 连接页嵌入功能简介。

### 手势

- 蜂巢墙上 **双指下滑**：隐藏 Mac 上全部已打开应用并显示桌面。

### 要求

- Mac 端建议 **1.3.0** 或更高，并与手机同一 Wi‑Fi 配对。

### 安装包

- CDN（国内推荐）：https://models.appda.store/treelethub/TreeletHub.apk
- GitHub 附件：`TreeletHub-Android-1.3.1.apk`（`versionCode` 6）
- 也可从 [Google Play](https://play.google.com/store/apps/details?id=com.treelet.treelethub) 安装

### 侧载安装（APK）

1. 下载 APK。
2. 在系统设置中允许「安装未知应用」（按机型路径略有差异）。
3. 打开 APK 完成安装。
4. 与 Mac 同一 Wi‑Fi，打开 TreeletHub 输入配对码连接。
