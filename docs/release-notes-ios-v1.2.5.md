## TreeletHub iOS 1.2.5

### 新功能：AI 控制键盘

在九宫格中点按 **ChatGPT、Codex 或 Cursor**，手机不再只是启动 Mac 应用，而是进入该应用专属的 **控制键盘**（左上角返回九宫格）。

- **Codex**：Agent 状态灯、批准 / 拒绝、新会话继续、推理旋钮、Skills 等。
- **ChatGPT**：新对话、听写、发送、命令菜单、侧边栏等聊天向布局。
- **Cursor**：Chat、接受 / 拒绝、终端、命令面板等 IDE 向布局。
- 各应用键位与摇杆映射 **分别保存**，互不影响。

### 手机端听写（PTT）

- 按住 **PTT** 用 iPhone 麦克风说话；松手后识别文字填入 Mac 上对应应用的输入框。
- 双击可进入免提听写；识别完成后点 **Send** 发送。

### 安全与体验

- 旋钮转动仅本地切换推理档位，按下才确认，避免误触刷屏。
- 「命令面板自动输入」默认关闭；需要时在键盘设置中开启。
- 连接状态卡显示配对、目标应用、Mac 辅助功能权限。

### 系统要求

- iOS 17.6 或更高
- Mac 端需更新至 **1.2.7** 或更高，并与 iPhone 同一局域网配对
- 首次听写请允许 **麦克风** 与 **语音识别**
