## TreeletHub 1.3.2 for Android

与全端 **1.3.2** 对齐：在蜂巢启动墙上支持官网 TreeletHub Pro 的 **键盘与鼠标** 遥控；`versionCode` = **7**。

### 键盘与鼠标（需官网 Pro Mac）

- 配对后，若 Mac 蜂巢里有「键盘与鼠标」快捷方式，点该格即可当触控板与键盘用。
- 支持单指移动 / 左键、右键、双指滚动、文字输入与常用修饰键。
- **Mac App Store 版不会出现此项**；需在 Mac「系统设置 → 隐私与安全性 → 辅助功能」允许 TreeletHub Pro。

### 延续 1.3.1

- Watch 风格蜂巢启动墙：捏合缩放、拖动浏览、长按编辑换位。
- 点按启动 Mac 应用 / 快捷方式；音量、亮度、媒体走内联控件。
- 双指下滑：显示桌面。
- Pro 能力以 Mac 端为准（本机无 Play 订阅门控）。

### 要求

- Mac 端建议 **1.3.2**（官网 TreeletHub Pro）以使用键鼠；蜂巢遥控至少 **1.3.0+**。
- 与手机同一 Wi‑Fi 配对。

### 安装包

- CDN（国内推荐）：https://models.appda.store/treelethub/TreeletHub.apk
- GitHub 附件：`TreeletHub-Android-1.3.2.apk`（`versionCode` 7）
- 也可从 [Google Play](https://play.google.com/store/apps/details?id=com.treelet.treelethub) 安装

### 侧载安装（APK）

1. 下载 APK。
2. 在系统设置中允许「安装未知应用」（按机型路径略有差异）。
3. 打开 APK 完成安装。
4. 与 Mac 同一 Wi‑Fi，打开 TreeletHub 输入配对码连接。
